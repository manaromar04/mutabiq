# Mutabiq synthetic invoice dataset

Generated by `python -m data_generator.generate --out data/synthetic --seed 2026`.
The same seed always produces the same dataset. All companies, TRNs and IBANs are invented.

## Contents

| File / folder | Description |
|---|---|
| `documents/` | 312 invoices and credit notes: PDF, scanned JPG, phone-photo JPG, XLSX |
| `ground_truth/` | One JSON per document with every field exactly as printed, plus layout, language, variant and any planted error |
| `seller_profiles.json` | Master data for the 12 seller SMEs (trade licence, IBAN, default payment terms) |
| `manifest.csv` | One row per document |
| `injected_errors.csv` | One row per planted error and the component expected to catch it |

## Composition

- **12 seller SMEs**, 40 customers, 25 documents per seller, plus 12 duplicate uploads
- **Languages:** 180 English, 52 Arabic, 80 bilingual
- **Formats:** 167 digital PDF, 76 scanned, 44 phone photos, 25 Excel
- **Layouts:** 8 PDF templates (English, Arabic right-to-left with Western or Eastern Arabic digits, bilingual) + 1 spreadsheet format
- **Document types:** 295 tax invoices (380), 17 tax credit notes (381)

## Planted errors (83)

| Error | Count | Expected to be caught by |
|---|---|---|
| VAT miscalculated | 9 | Official PINT AE rules |
| Total does not add up | 9 | Official PINT AE rules |
| Line total wrong | 9 | Official PINT AE rules |
| Buyer TRN 14 digits | 9 | Official PINT AE rules |
| Buyer TRN wrong format | 9 | Official PINT AE rules |
| Buyer TRN missing | 9 | Official PINT AE rules |
| Due date before issue date | 8 | Mutabiq UAE checks |
| Unusually large amount | 9 | Anomaly detection |
| Duplicate upload | 12 | Anomaly detection |

`tests/test_dataset.py` confirms that all 229 clean documents produce valid PINT AE XML
(after the seller profile is applied) and that every error meant for the official rules is caught.
